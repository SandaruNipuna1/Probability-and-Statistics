# 📊 Probability and Statistics – Practical Labs

This repository contains practical laboratory exercises completed as part of the **Probability and Statistics (PAS)** hmodule at the **Sri Lanka Institute of Information Technology (SLIIT)**.

The practical work uses **R programming** to explore statistical concepts, analyze datasets, calculate probabilities, perform hypothesis testing, and visualize statistical distributions.

## 🧪 Laboratory Contents

| Lab    | Topics Covered                                                                              |
| ------ | ------------------------------------------------------------------------------------------- |
| Lab 01 | R fundamentals, variables, operators, vectors, matrices and data frames                     |
| Lab 02 | Loops, conditional statements, vector operations and basic problem-solving                  |
| Lab 03 | Data importing, descriptive statistics, histograms, bar charts, box plots and data analysis |
| Lab 04 | R programming practical exercises                                                           |
| Lab 05 | Frequency distributions, histograms, cumulative frequencies and ogives                      |
| Lab 06 | Discrete probability distributions: Binomial and Poisson distributions                      |
| Lab 07 | Continuous probability distributions: Uniform, Exponential and Normal distributions         |
| Lab 08 | Population and sample statistics, sampling distributions, sample means and standard errors  |
| Lab 09 | Random sampling and statistical hypothesis testing using one-sample t-tests                 |
| Lab 10 | Additional probability and statistics practical exercises                                   |

## 🚀 Running the R Scripts

1. Install [R](https://cran.r-project.org/).
2. Install [RStudio](https://posit.co/download/rstudio-desktop/).
3. Clone or download this repository.
4. Open the relevant `.R` file in RStudio.
5. Make sure any required datasets are available in the working directory.
6. Run the code to reproduce the practical exercises and results.
